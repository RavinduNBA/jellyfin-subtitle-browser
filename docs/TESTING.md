# Tester checklist

Try a short, non-sensitive video first. Record the release version and Windows version.

- Start and pause playback; seek backward and forward.
- Open the transcript using the icon next to CC. Confirm it closes fully with the Windows X.
- Move and resize it, close it, then reopen it.
- Increase font size, restart the whole player, and confirm it is restored.
- Scroll to reread; use Back to current line; double-click a line to replay.
- Try SRT and ASS/SSA tracks if available. Switch tracks and episodes.
- Confirm the icon is present on second and later playbacks.
- Check your chosen Jellyfin theme, including dropdown readability.
- If relevant, try a second monitor and reconnecting a display.
- Close the app and test uninstall. Confirm stock Jellyfin still works.

For a report, include expected versus actual behavior and exact steps. Redact server addresses, tokens, account names and personal media titles. Use the fork's own bug form, not upstream's tracker. Do not claim tests you did not perform.
